    RSVS v4.2 Latest Confirmation (Single Node + Semantic Compression)¶

    Date: 2026-04-22 Source checked: - backend/docs/skills/rsvs-v4.skill - extracted refs: context.md, notation.md, schema.md, SKILL.md

    Current Implementation Status (Latest)¶

    Status: implemented and verified (bridge runtime lane).

    Implemented: 1. Runtime hard-break schema - schema_version=v4.2 enforced. - Legacy payload (kind=composite / old schema) rejected with schema_version_mismatch.

    1. Single node model in bridge
    2. kind=node enforced.

    3. Semantic compression contract validated (compression_state, derived_from_node_ids, compression_reason).

    4. Policy engine governance in ingest path

    5. Seed bootstrap rule active (24 seed nodes):
    6. is_seed=true
    7. is_locked=true
    8. tier=1
    9. confidence=1.0
    10. status=stable
    11. Non-seed lifecycle active with hysteresis:
    12. promote threshold >= 0.75
    13. demote threshold < 0.60
    14. Dedup replay guard active (fingerprint-based) to prevent score inflation.

    15. Quarantine guard active when status flips exceed budget.

    16. Mode output contract alignment

    17. relate/appraise output now carries governance fields (status, confidence, is_seed, is_locked) through projection.
    18. view=compact|detail preserved.

    Verification evidence: 1. Targeted V4.2 test suite: - python/tests/test_bridge_v42.py => 6 passed in 0.14s

    1. Manual smoke run:
    2. ingest -> ingest ulang -> relate(detail) path passed.
    3. Seed invariants observed as expected.

    Notes: - Verification above is for Python bridge runtime scope. - Full backend matrix (all python/rust test suites) remains a separate run.

    Confirmed Core Rules (Latest)¶

    1. Integer-first representation
    2. ID is integer (int32) as primary identity.

    3. String/label mapping is output/helper layer only.

    4. Language handling

    5. Language identity in active model uses surface_label=<surface>@<lang>.
    6. Multilingual semantics remains pointer-based (batu@id : same_as stone@en) with strict equivalence gating.
    7. @lang suffix is part of primary surface-locale identity.

    8. Language labels are AI-assigned from data, not hardcoded in definition.

    9. Single node semantics

    10. Semua entitas semantik menggunakan model tunggal node.
    11. Tidak ada tipe ontologis terpisah composite.
    12. Kompresi dinyatakan sebagai metadata semantik (compression_state + provenance), bukan jenis node.

    13. Negation vs missing tetap dipisahkan tegas.

    14. Seed policy

    15. 24 seed atoms (Layer 0 + Layer 1) are mandatory at startup.
    16. Seed atoms have confidence 1.0, Tier 1, and cannot be removed.

    17. Layer 2+ atoms emerge from data.

    18. Compression + sense policy

    19. compression_state:
    20. raw: node dasar hasil sinyal ingest.
    21. compressed: node ringkas yang merefer ke node asal.
    22. derived_from_node_ids wajib valid untuk compressed.

    23. sense_state tetap data-formed dan tidak hardcoded.

    24. Attention + scoring

    25. RSVS Attention uses hard selection (sparse) with:
    26. score = α*NPMI + β*Jaccard + γ*cooc

    27. NPMI (bounded) is required, not PMI.

    28. Tiered autonomy

    29. Tier 1: autonomous
    30. Tier 2: flagged/candidate (revocable)
    31. Tier 3: blocked (human decision)
    32. Confidence update formula is explicitly defined in latest context.

    Corrections Locked (Post Senior Review)¶

    1. Language wire format is no longer open
    2. Final direction: use surface@lang + pointer relation (same_as).

    3. Not using "reserved atom pattern" for language semantics.

    4. Negation vs missing must both be explicit

    5. Keep both semantics:
    6. explicit negation: weight: 0.0 + negated: true
    7. missing/unclassified: outside atom_refs (or dedicated missing field)

    8. Do not allow weight: 0.0 without negated: true.

    9. Seed lock enforcement is both runtime and persisted

    10. Runtime rule + persisted fields are both required.

    11. Keep is_seed, is_locked, and non-revocable autonomy signals.

    12. Sense-aware weighting is required

    13. Add sense-scoped weighting or sense-level atom weights.

    14. sense_state must be populated (not always empty).

    15. Language framing correction

    16. Language context is encoded in surface_label suffix (@lang).
    17. Pointer mapping (same_as) remains for cross-language equivalence.

    18. sense_state is optional/secondary in this reconstructed model.

    19. Hard break schema policy

    20. Payload lama (schema_version tidak sesuai atau kind=composite) ditolak.
    21. Writer hanya menulis schema v4.2.
    22. Reader mengembalikan error schema_version_mismatch untuk artefak lama.

    JSON/Schema Implications (Must Follow)¶

    1. Use pointer-based multilingual links
    2. Example relation: same_as.

    3. Collision example via surface_label: air@id, air@en.

    4. Distinguish explicit negation vs unknown

    5. Explicit negation in atom_refs with paired fields.

    6. Missing/unclassified represented separately from positive refs.

    7. Single node + compression invariants

    8. kind harus node (jika field dipertahankan).
    9. semantic.compression_state enum: raw | compressed.
    10. Jika compressed, wajib:
    11. semantic.derived_from_node_ids non-empty.
    12. semantic.compression_reason non-empty.

    13. derived_from_node_ids tidak boleh self-id, duplikat, atau referensi node yang tidak ada.

    14. Persist and enforce seed lock

    15. Persisted fields + runtime checks must both exist.

    16. Keep mode outputs ID/edge-grounded

    17. Appraise/Relate evidence should refer to node IDs/relations, not summary text only.
